# 英语阅读讲解器

上传英语阅读试卷图片（或直接粘贴文本），AI 自动识别、切分段落、定位答案，生成逐题讲解页。

- 单文件网页，双击就能用；在线版：https://wayland123456.github.io/reading-locator/
- 解析走免费档（智谱 GLM-4.7-Flash / GLM-4.6V-Flash），首次使用需在页面右上角「🔑 免费Key」贴一次自己的智谱 Key（只存在本机浏览器）
- 快捷键：`←` `→` 切题、`Ctrl+V` 粘贴截图、双击段落改原文、单击选项改答案
- 云端课件库：家里做好讲解，教室填同一口令打开（需先在 Supabase 建 `reading_lessons` 表）

配套说明见桌面 `英语阅读讲解器_配置与使用.md`。
